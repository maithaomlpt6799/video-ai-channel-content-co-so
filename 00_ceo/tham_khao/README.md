# Tham khảo của CEO

Nơi CEO thả tài liệu để "dạy" cả phòng. Agent đọc khi làm việc liên quan. Mỗi file một chủ đề:

| File gợi ý | Ai đọc |
| --- | --- |
| `kenh_tham_chieu.md` — kênh anh lấy cảm hứng, kênh đối thủ (link + thích / không thích gì) | Research, Manager, Creative |
| `video_mau_hay.md` — video anh thấy hay (link + vì sao) | Content, Codex, Creative |
| `giong_viet.md` — câu anh hay nói, từ nên / không nên dùng | Codex, Social |
| `chien_luoc_chatgpt.md` — tóm tắt các quyết định từ chat "Chiến lược kênh content" | Manager, Content |
| `feedback_tong_hop.md` — góp ý lặp lại nhiều lần (Manager tổng hợp, CEO duyệt rồi chép vào đây) | Tất cả |

Khi một góp ý lặp lại ≥ 2 lần, CEO nên chuyển nó thành luật trong sổ tay vai (`vai/`) để agent không tái phạm.
