# Kế hoạch tháng đã chốt

Mỗi tháng một file `<yyyy-mm>.md`, Manager lưu **nguyên văn** bản CEO chốt (qua `/nhan-ke-hoach`). Agent chỉ đọc.

## Khuôn để ChatGPT trả về kế hoạch chốt

Khi bàn xong với ChatGPT, CEO dán đoạn này để ChatGPT trả về đúng khuôn Manager nhận được:

```
Viết lại kế hoạch chốt theo đúng khuôn dưới đây, không thêm lời dẫn.

# Kế hoạch tháng <mm/yyyy> — Content Có Số
## Mục tiêu tháng
## Trend / vấn đề bám
## Keyword chủ lực
## Hashtag chủ lực
## Lịch tập (T2 · T4 · T6)
| Ngày | Tiêu đề làm việc | Pillar | Format | Insight 1 câu | Trend / vấn đề bám | Keyword | Ghi chú cho người viết |
## Điều cần tránh
```

Pillar chỉ nhận: Bóc lỗi Content · Giải mã Content hay · Content thực chiến.
Format chỉ nhận: So sánh (Before/After) · Giải mã (Breakdown) · Một ý lớn (Kinetic) · Kể chuyện (Story) · Khác.
